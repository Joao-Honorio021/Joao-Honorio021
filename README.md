## 🤖 Robotics Experience — TBR (Brazilian Robotics Tournament)

I participated in the **TBR (Brazilian Robotics Tournament)** as a **programmer and robot assembly member** of the **Fênix Furious** team, competing in the **High category** using **LEGO-based robots**.

- 🧱 Hardware platform: **LEGO SPIKE Prime**
- 💻 Programming environment: **Pybricks (Python)**

### Technical Skills Developed:
- Object-Oriented Programming (**OOP**) applied to robotics
- Implementation of **Finite State Machines (FSM)** to control robot behavior
- Robot movement logic, sensors integration, and task automation
- Testing, debugging, and performance optimization under competition constraints
- Mechanical assembly and structural adjustments of the robot

This experience allowed me to apply programming concepts in a **real-world competitive environment**, strengthening my logical thinking, software structure skills, and teamwork under pressure.
